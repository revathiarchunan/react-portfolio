
# Revathi | Frontend Developer Portfolio

A responsive personal portfolio website built with React to showcase my projects, technical skills, and contact information.

## Live Demo
## Live Demo
https://revathi-react-portfolio.netlify.app/

## Features
- Responsive design for desktop and mobile
- Dark and light theme toggle
- React Router navigation
- Projects showcase
- Contact form with validation
- Contact form email integration
- Mobile-friendly navigation

## Tech Stack
- React.js
- JavaScript
- HTML5
- CSS3
- React Router
- Vite
- FormSubmit

## Projects
- **Nexora Digital** – Responsive landing page
- **UAE Job Tracker** – Job application tracking application
- **React Portfolio** – Personal developer portfolio

## Run Locally

Clone the repository:

```bash
git clone https://github.com/revathiarchunan/react-portfolio.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
